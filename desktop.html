Hướng Dẫn Kết Nối Google Sheets API

Website của bạn đã được cấu hình sẵn để kết nối với Google Script API của bạn:

https://script.google.com/macros/s/AKfycbyK6MP86Twyh4UAGqACHmYmxgdxh_5Zhi7RGrqfsQozEsKZFs6ZUwquHA-yZuiv_TDZ/exec

1. Cấu trúc các cột trên Google Sheet:

Tại trang tính đầu tiên (Sheet1 hoặc Transactions), hãy đặt tiêu đề hàng 1 theo thứ tự:

  • Cột A: id (Mã giao dịch)
  • Cột B: date (Ngày giao dịch - YYYY-MM-DD)
  • Cột C: type (income hoặc expense)
  • Cột D: category (Mã danh mục: food, shopping...)
  • Cột E: amount (Số tiền VND)
  • Cột F: note (Ghi chú)
  • Cột G: createdAt (Thời gian tạo)

2. Cài đặt quyền truy cập Apps Script:

Khi triển khai (Deploy) Web App trên Google Apps Script, hãy đảm bảo:

  • Execute as: Me (Tôi)
  • Who has access: Anyone (Bất kỳ ai) (Để trình duyệt không bị chặn bởi trang đăng nhập Google)

👉 Xem toàn bộ mã nguồn Apps Script chuẩn trong file GOOGLE_SHEET_GUIDE.md trong thư mục dự án.
